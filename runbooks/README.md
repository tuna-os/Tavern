# Tavern Operational Runbooks

This directory contains operational runbooks for maintaining the `tuna-os/Tavern` GTK4/Adwaita application ecosystem, flatpak publishing, and catalog curation.

## Runbooks Index

- [Flatpak Release & Validation Runbook](flatpak-release-and-validation.md) - Procedures for validating Flatpak builds, checking AppStream metadata compliance, verifying runtime dependencies, and executing release candidate tests.
- [Incident Response & Postmortem Runbook](incident-response.md) - Standard operational procedures for triaging critical app regressions, CI failures, and filing incident postmortems.
