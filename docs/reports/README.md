# Historical verification reports

Each file here is the record of one investigation at one point in time.
It keeps the environment, commands, and conclusions from the date that the
report shows. We do not keep these files current as instructions to install,
develop, or release Tavern.

Use the maintained documentation instead:

- [README](../../README.md) for supported installation channels and user setup;
- [contributor guide](../../CONTRIBUTING.md) for development and tests; and
- [release guide](../RELEASING.md) for the current release contract.

Commands, repository locations, package versions, and artifact formats in a
historical report may no longer be supported. Verify current behavior against
the maintained documentation before you repeat the procedure of a report.
