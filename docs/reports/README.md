# Historical verification reports

The files in this directory record point-in-time investigations. They preserve
the environment, commands, and conclusions from the date shown in each report;
they are not maintained as installation, development, or release instructions.

Use the maintained documentation instead:

- [README](../../README.md) for supported installation channels and user setup;
- [contributor guide](../../CONTRIBUTING.md) for development and testing; and
- [release guide](../RELEASING.md) for the current release contract.

Commands, repository locations, package versions, and artifact formats in a
historical report may no longer be supported. Verify current behavior against
the maintained documentation before repeating a report's procedure.
